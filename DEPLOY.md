# Deploy na Vercel

## Repo
https://github.com/Huskymc/librus-synergia-demo

## Krok 1 – wrzuć aplikację
1. Pobierz plik `librus-klon.html` (z czatu / lokalnie).
2. Na GitHubie: **Add file → Upload files**.
3. Wrzuć plik i nazwij go **`index.html`** (zastąp istniejący).
4. Commit.

## Krok 2 – Vercel
1. Wejdź na https://vercel.com/new (zaloguj kontem GitHub).
2. **Import** repozytorium `librus-synergia-demo`.
3. Framework Preset: **Other**.
4. Build Command: puste.
5. Output Directory: puste / `.`
6. **Deploy**.

Po deployu strona będzie pod adresem typu:
`https://librus-synergia-demo.vercel.app`

Na HTTPS **localStorage działa poprawnie** (klasy, nauczyciele itd. zostają po odświeżeniu).
